# 采集产品模块 - 前端页面设计

## 页面结构

```
/collected-products              → 列表页（主入口）
/collected-products/[id]         → 详情/编辑页

/settings                        → 系统设置（已有页面）
  ├── WooCommerce 配置            → 新增子页面
  ├── 翻译配置                    → 新增子页面
  └── 采集 API Token             → 新增子页面
```

### 关键交互

| 交互 | 说明 |
|------|------|
| **状态标签页** | 点击切换筛选，实时更新列表。各标签显示对应数量 |
| **勾选 + 批量操作** | 勾选多个 `ready` 状态的产品 → "发布到独立站"按钮亮起 |
| **点击行** | 跳转到详情/编辑页 `/collected-products/[id]` |
| **状态标签** | 每一行显示彩色状态标签：待梳理(灰)、梳理完成(蓝)、已发布(绿)、发布失败(红) |
| **主图缩略图** | 显示该产品的主图（如有），无图显示占位符 |

### 状态标签配色

| 状态 | 标签色 |
|------|--------|
| collected（待梳理） | 灰色 |
| organizing（梳理中） | 蓝色 |
| ready（梳理完成） | 青色 |
| publishing（发布中） | 黄色（加载动画） |
| published（已发布） | 绿色 |
| error（发布失败） | 红色 |
| discarded（已废弃） | 灰色+删除线 |

### 关键交互

| 交互 | 说明 |
|------|------|
| **AI 翻译按钮** | 点击后调用翻译 API，结果填入对应的英文字段，不自动保存（需用户确认） |
| **保存时弹窗** | 如果该产品已发布（published），保存修改后弹窗询问"是否同步到 WooCommerce？" |
| **图片预览** | 点击图片可放大预览（图片从数据库 bytea 读取后以 data URL 展示） |
| **变体表格** | 行内编辑，点击单元格直接修改 |
| **发布按钮** | 点击后先调 convert（如未转正），再调 publish，显示进度 |
| **底部操作栏** | 按钮根据当前状态显示/隐藏（如已发布状态不显示"发布"按钮） |

## 四、侧边栏菜单

在 `menuConfig` 中「产品中心」分组下新增：

```typescript
{
  key: 'collected-products',
  label: '采集产品管理',
  icon: Download,  // 或 CloudDownload
  href: '/collected-products',
  roles: ['admin', 'sales'],
}
```

## 五、页面文件结构

```
src/app/
├── collected-products/
│   ├── page.tsx              ← 列表页
│   └── [id]/
│       └── page.tsx          ← 详情/编辑页
└── settings/
    ├── woocommerce/
    │   └── page.tsx          ← WooCommerce 配置
    ├── translation/
    │   └── page.tsx          ← 翻译配置
    └── collect-token/
        └── page.tsx          ← 采集 Token
```
